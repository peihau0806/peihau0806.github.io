關於我aka一邊迷惘一邊努力活著的大一生

我是誰

我是莊沛樺，畢業於宜蘭高商多媒體設計科， 現在就讀設計相關科系。雖然目前還在大一迷惘期， 但也正在慢慢摸索自己到底喜歡什麼、適合什麼。

平常喜歡做什麼

  • 聽音樂，尤其是 rock、hip-hop 之類的
  • 彈吉他，雖然有時候比較像在製造噪音
  • 玩遊戲，像是英雄聯盟、Valorant、Minecraft
  • 做設計、亂看靈感、想一些奇怪點子

我的個性

我覺得自己算是活潑、情緒很多、腦袋也很多小劇場的人。 有時候會很迷惘，但也不是真的想放棄， 比較像是一邊吐槽人生一邊還是繼續往前走。

為什麼做這個網站

這個網站是課堂作業的一部分， 目的是把這學期學到的網頁技術整合起來。 對我來說，它不只是作業，也有點像是把現在的自己記錄下來。

目前學到的技能

  1. HTML 基本結構
  2. CSS 美化與排版
  3. Flex 版面配置
  4. Git 版本控制
  5. GitHub Pages 網站發佈

現在的我

現在的我還沒有很厲害，也還在試著找到自己的方向， 但至少我把這個網站做出來了。某種程度上，這也算是一個開始。
